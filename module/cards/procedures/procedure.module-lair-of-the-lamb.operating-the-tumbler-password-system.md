# Operating the Tumbler Password System

## Operational fields

### Steps

- Set each disk to a number from 1 to 8.
- Pull the lever.
- If the setting is 1-2-1-2, open the door to 7 THRONE.
- If the setting is incorrect, produce a horrible grinding noise every time and spray milky acid once; the acid deals 1d6 diminishing damage each turn until rinsed off.

### Trigger

A character sets the four rotating disks and pulls the lever in 6 TUMBLERS.
