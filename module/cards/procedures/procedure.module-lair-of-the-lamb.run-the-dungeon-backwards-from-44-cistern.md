# Run the Dungeon Backwards from 44 CISTERN

## Operational fields

### Steps

- Have the characters enter through 44 CISTERN, which is at the bottom of a well.
- Remove the underwater tunnel and the wall from 44 CISTERN so section 2 is accessible.
- Add an ooze to 14 MOLD.
- Add a candle golem to 5 LANDING.

### Trigger

When preparing the dungeon to be played backwards.
