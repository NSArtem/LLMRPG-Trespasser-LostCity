# Return through the candle ward

- ID: `procedure-return-through-candle-ward`
- Type: `procedure`
- Source pages: 20
- References: `location-area-14-warded-pool`, `procedure-cross-candle-ward`

## Operational fields

### Steps

- Characters who originally came from the tomb can pass back through.
- The ward is impassable to others.

### Trigger

A character in Fairy attempts to pass back through the ward toward the tomb.
