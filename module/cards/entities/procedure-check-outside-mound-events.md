# Check Random Events Outside the Mound

- ID: `procedure-check-outside-mound-events`
- Type: `procedure`
- Source pages: 11
- References: `location-outside-the-mound`, `table-outside-mound-random-events`

## Operational fields

### Steps

- Check for a random event with a 1-in-6 chance.
- If an event occurs, use one of the four entries in the Outside the Mound random event table and resolve its stated mechanics.

### Trigger

The party spends two turns outside the burial mound.
