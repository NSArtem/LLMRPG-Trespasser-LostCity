# Morale

## Operational fields

### Text

A monster that fears death flees rather than be destroyed; even elementals and undead recoil from annihilation. When morale calls for flight but escape is impossible, monsters attempt surrender. If the players appear not to take prisoners, they continue fighting. When uncertain whether a monster chooses intelligently, make an Int check for it. Chasing fleeing monsters uses the same Pursuit rules as player flight.
