# Ghost Fence Instant Death and Formation Dependence

## Operational fields

### Text

If the heads are touched or someone passes over them, the nearest living thing dies with no Save. Moving any head out of the specific formation ends the effect; returning the heads to formation restores it. The heads can be transported and set up elsewhere with the same effect.
