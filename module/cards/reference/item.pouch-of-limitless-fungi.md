# Pouch of Limitless Fungi

## Operational fields

### Text

An ordinary-looking burlap belt pouch filled with colourful mushrooms. It never runs out. The first mushroom a character eats each day produces a random magical effect on 1d12; later mushrooms that day make the character sick. Unless an entry says otherwise, the effect is permanent.
