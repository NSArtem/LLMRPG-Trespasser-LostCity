# Never Fudge or Retune Mid-Encounter

## Operational fields

### Text

Never fudge the dice or alter a creature or trap during an encounter. If combat is too difficult, the PCs can flee using Pursuit; if it is too easy, wrap it up quickly and move on using Morale.
