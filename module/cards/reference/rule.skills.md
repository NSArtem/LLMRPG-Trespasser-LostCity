# Skills

## Operational fields

### Text

Anything improvable through practice or study can be a Skill; all professions and college majors qualify. There is no fixed Skill list or fixed list of Skill uses. Social, perception, stealth, and direct combat Skills do not exist. At the end of each session, each PC may choose a Skill used or encountered during the session and make an Int check. Broad exposure counts, but the same book or library cannot teach the same subject twice. Success raises the Skill by 1, to a normal maximum of 9; the 10th point requires a quest. A character has 4 Skill Slots shared by Skills and Languages.
