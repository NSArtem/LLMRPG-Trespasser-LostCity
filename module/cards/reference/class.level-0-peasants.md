# Level 0 Peasants

## Operational fields

### Text

In this introductory adventure, every player controls multiple level 0 peasants. They have no special abilities and die in a single hit; the multiple peasants give players extra lives while they learn the system. The game begins with 12 level 0 peasants in a dungeon; unless there are more than 6 players, each player controls multiple peasants, choosing one as their PC and treating the rest as hirelings.
