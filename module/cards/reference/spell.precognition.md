# Precognition

## Operational fields

### Text

Range 0; target self; duration 0. The caster sees what will happen [dice] rounds into the future if following a specific course of action. Resolve this as a very quick solo game with the GM, using no dice and taking about 20 seconds, to explore that possible future.
