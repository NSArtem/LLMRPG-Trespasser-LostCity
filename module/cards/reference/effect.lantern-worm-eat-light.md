# Eat Light

## Operational fields

### Text

A targeted light source explodes and is destroyed. The lantern worm consumes the light and becomes brighter. The holder takes 1d6 fire damage unless a Wis Save negates it and is automatically blinded. Everyone else is blinded on a failed Wis Save. Each blinded character makes a Con check each turn to end the blindness.
