# Liquid Boat

## Operational fields

### Text

A vial containing a full-size ship in liquid form; it smells like the ocean and tastes like tarred wood. One drop forms a toy boat, one quarter of the vial forms a rowboat for 4, one half forms a small sloop for 8, and the whole vial forms a full-size ship for 16. If space is insufficient, the result is a deformed nonsense boat. If consumed, the drinker becomes a self-aware boat that can communicate only by creaking.
