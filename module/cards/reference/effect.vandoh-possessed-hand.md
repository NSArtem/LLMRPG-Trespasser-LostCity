# Vandoh's Possessed Left Hand

## Operational fields

### Text

The first person to speak or pray to the statue has their left hand possessed. The hand is rigid and holds up a number of fingers equal to the number of ghouls remaining in the dungeon. Whenever a ghoul is encountered, the hand clenches with rage.
