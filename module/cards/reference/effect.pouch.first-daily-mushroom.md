# First Mushroom of the Day

- ID: `effect.pouch.first-daily-mushroom`
- Type: `effect`
- Source pages: 26
- References: `item.pouch-of-limitless-fungi`, `table.pouch.random-shroom-effects`

## Operational fields

### Text

The first mushroom a character eats each day produces one random magical effect determined by 1d12. Unless the rolled entry states otherwise, that effect is permanent.
