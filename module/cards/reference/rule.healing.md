# Healing

## Operational fields

### Text

After a 10-minute rest, everyone recovers HP up to half maximum. After a 30-minute rest with one Ration, everyone recovers all HP; one Ration feeds the whole party. If combat interrupts the meal, no healing occurs before combat, but the party can resume the rest from where it stopped.
