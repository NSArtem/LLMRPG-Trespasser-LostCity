# Attacking and Defending

## Operational fields

### Text

The attack DC depends on the target's armor. Level 0 peasants have Atk 0. If multiple PCs attack the same target simultaneously and roll simultaneously, each gains +1 to the attack roll for every attacker beyond the first. The DC to defend against an enemy equals 12 + the attacker's Level. A character's Def score is determined entirely by armor.
