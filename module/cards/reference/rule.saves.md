# Saves

## Operational fields

### Text

Saves use Dex, Con, or Cha against DC 20. Cha applies to all magical effects and is the most common Save. If a failed Save nearly kills a character, that character permanently gains +4 to that type of Save and records the event in the Legendarium on the back of the character sheet. Each character has 4 Save Slots.
