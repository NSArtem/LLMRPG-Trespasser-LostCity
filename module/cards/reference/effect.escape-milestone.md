# Escaping the Dungeon Is a Milestone

## Operational fields

### Text

Removing the heavy bar from 21 HEAVY DOORS grants a Milestone because the party has escaped from the Lamb, unless the Lamb has already been killed. Reaching freedom outside the dungeon also counts as a Milestone.
