# Персонаж: Бьорн

## Концепция

Сильный и решительный бывший шахтёр, ведущий группу через физические
опасности `The First Day`.

## Игровые показатели

- **Система / архетип / класс:** Trespasser v2.1.3; Commoner; Miner.
- **Уровень / ранг / опыт:** commoner, до 1-го уровня.
- **Alignment:** Daring, Greedy.
- **Атрибуты:** Might 3, Agility 1, Intellect 0, Spirit 1.
- **Skill:** Athletics; skill bonus +2, skill die d6.
- **Combat values:** HP 8; Speed 5; Initiative +3; Accuracy +5; Guard 1;
  Resist 3; Prevail 2.
- **Armor:** отсутствует.

## Здоровье и состояния

- **Текущее / максимальное здоровье:** `8/8 HP`.
- **Endurance / recovery dice:** отсутствуют у commoner.
- **Состояния:** почти наг; мокрая одежда в тюке; покрыт кровью убитого
  существа. Механическая plight не назначена.

## Способности

- Участвует в Commoner Mob.
- Commoner weapon: `2d4`, при combat spark может confer toppled.
- Commoners не делают Tenacity checks и погибают при достижении 0 HP.

## Инвентарь

- Кирка — commoner weapon и инструмент.
- Ржавый тесак — найден на утопленнике; точные weapon tags не установлены.
- Тюк мокрой одежды.

## Расходуемые ресурсы

- Нет источника света, пищи или воды.

## Отношения

- Действует совместно с Эльзой и Годвином.
- Был рядом при гибели Марты.

## Цели

- Вывести группу из подземелья.
- Найти свет и безопасный путь.

## Знания и важные разговоры

- Знает весь пройденный группой маршрут.
- Нащупал окованную дверь и видел свет из-под неё.

## Известные секреты

- Нет.

## Заметки по развитию

- Если переживёт `The First Day`, может быть выбран для повышения до 1-го
  уровня.
