# Шаблон состояния до кампании

Этот каталог содержит неизменяемую системно-нейтральную копию файлов,
которые должны находиться в корне репозитория перед подготовкой новой
кампании.

Рабочие файлы по-прежнему находятся в корне. Не редактируйте содержимое
`templates/` при подготовке или ведении конкретной игры: оно используется
скриптом `scripts/reset_campaign.sh` как источник восстановления.

`reset-paths.txt` — исчерпывающий список путей, которые разрешено заменять.
Каждый путь из списка должен иметь одноимённый файл или каталог здесь.
