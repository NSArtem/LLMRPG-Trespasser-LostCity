# Journal entries

Каталог компактной append-only истории кампании. До начала игры он содержит
только этот файл и шаблон.

## Правила

- Используйте последовательные имена `entry-0001.md`, `entry-0002.md`.
- Стабильный ID имеет вид `journal.entry-0001`.
- Открытую запись можно дополнять новыми checkpoint-блоками.
- Закрытую запись не переписывают.
- Граница чата или календарного дня не закрывает сцену или запись.

## Рабочий порядок

1. При старте кампании создать `entry-0001.md` из шаблона.
2. Указать его ID и активную сцену в `CURRENT.md`.
3. На каждом checkpoint дописывать компактный блок событий и последствий.
4. Закрывать запись по смысловой или размерной границе.
