# Краткая памятка правил

Источник: `Trespasser v2.1.3 - Rulebook.pdf`. Это краткая навигация, а не
замена оригинального текста.

## Проверки

- Обычная skill check: `d20 + attribute + skill bonus`, если навык известен.
- Target Number для hostility tier `0 / First Day` обычно равен 10.
- За каждые полные 5 выше TN игрок получает spark; за каждые полные 5 ниже
  TN ведущий назначает shadow.
- Sparks дают качества результата (`canny`, `quick`, `quiet`, `safe`,
  `striking`); shadows — противоположные последствия.
- Shadow warning означает заранее объявленную дополнительную ставку. Успешный
  противоположный spark может её banish.
- Темнота добавляет дополнительную shadow к задаче, которой помогает зрение;
  она не превращает бросок в `2d20, взять худший`.

## Commoners и Mob

- Commoner HP: `5 + Might`; Endurance и recovery dice отсутствуют.
- При 0 HP commoner сразу погибает, без Tenacity check.
- Combat values: Speed 5, Initiative `Agility + 2`, Accuracy
  `max(Might, Agility) + 2`, Guard `Armor + Agility`, Resist `Spirit + 2`,
  Prevail `Intellect + 2`.
- До четырёх commoners образуют Mob в бою: одна клетка, один ход, 3 AP.
- Общий check использует лучший подходящий бонус среди членов Mob.
- Одиночная вражеская атака выбирает одного commoner случайно; урон не
  распределяется игроком.
- `Mob Attack` стоит 1 AP и использует оружие выбранного commoner; за каждый
  дополнительный AP может атаковать ещё один commoner.

## Dungeon frame

- Один dungeon round длится 30 минут и состоит из трёх групповых actions.
- Combat обычно не тратит dungeon action, но повышает alarm на 1.
- После трёх actions: depletion checks активного света, alarm +1 и alarm
  check `d10 ≤ alarm`; при встрече alarm сбрасывается в 0.
- Alarm также растёт из-за громкого шума, ловушки, боя или иного привлечения
  внимания.
- Основные actions текущей ситуации: `Explore`, `Interact`, `Pick Lock`,
  `Search`, `Traverse`, `Vandalize`, `Hide`, `Moment's Rest`.

## The First Day

- Игрок начинает с двух-четырёх commoners.
- После завершения First Day выбирается один выживший для повышения до
  1-го уровня; остальные выжившие могут перейти другим игрокам.
