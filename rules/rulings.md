# Решения по правилам

## RUL-001 — Жажда в пирамиде

- **Статус:** active
- **Система:** Trespasser v2.1.3
- **Принято:** `cp-0001`
- **Ситуация:** в Trespasser жажда относится к fiction Endurance, но в исходном чате не была найдена законченная процедура обезвоживания для текущего dungeon crawl.
- **Решение:** используется публичный таймер из 6 сегментов, начавшийся с 3/6. В конце каждого dungeon round без воды он увеличивается на 1. После заполнения каждый персонаж без настоящей воды теряет 1 HP в конце каждого следующего dungeon round. Разовая замена жидкости может отменить один тик, но не сбрасывает таймер.
- **Обоснование:** сохраняет давление выживания из B4 и ритм Dungeon Frame без добавления сложной подсистемы.
- **Источник:** ruling исходного чата; Trespasser v2.1.3, fiction Endurance и Dungeon Frame; отдельной прямой страницы с процедурой обезвоживания не найдено.
- **Приоритет:** ниже house rules, выше общего знания модели.

## RUL-002 — Гемолимфа огненных жуков

- **Статус:** active для аналогичной ситуации
- **Система:** Trespasser v2.1.3
- **Принято:** `cp-0001`
- **Ситуация:** персонажи попытались получить жидкость из трёх убитых огненных жуков.
- **Решение:** из трёх тел получилось три порции. Одна порция требует `MIGHT` check против 10 с предупреждённым `Harmful 1`. Успех отменяет 1 HP урона от жажды только в конце текущего dungeon round; провал не помогает. Если harmful не изгнан spark `Safe`, пьющий теряет 1 Endurance. Дополнительные shadows применяются по обычным правилам.
- **Обоснование:** отвратительная жидкость даёт отчаянный, рискованный и ограниченный шанс, не заменяя настоящую воду.
- **Источник:** ruling исходного чата; не является правилом модуля или Trespasser.
- **Приоритет:** ниже house rules, выше общего знания модели.

## RUL-003 — Закрывающаяся дверь во время первого боя

- **Статус:** resolved; применять только как прецедент для той же двери
- **Система:** Trespasser v2.1.3
- **Принято:** `cp-0001`
- **Ситуация:** Тавра стянула Нару с самозакрывающейся двери, пока семь гоблинов стояли по другую сторону.
- **Решение:** дверь закрывалась не мгновенно: два ближайших гоблина успели выйти в коридор, остальные получили по одному выстрелу через сужающийся проём.
- **Обоснование:** учитывает физическое положение, вес двери и десятисекундный combat round.
- **Источник:** ситуационный ruling исходного чата; состояние двери теперь изменено и записано в module overrides.
- **Приоритет:** прецедент для согласованности fiction, не общее новое правило.
