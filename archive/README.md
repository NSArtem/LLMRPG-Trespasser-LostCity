# Архив

Сюда переносятся неактуальные материалы, которые нужны для истории, но не должны загружаться в контекст по умолчанию.

## Что архивировать

- завершённые сюжетные линии;
- погибших или окончательно выбывших NPC;
- старые снимки состояния;
- отменённые планы;
- устаревшие версии документов.

## Правила

- Сохраняйте стабильные ID и указывайте причину и checkpoint архивирования.
- Не переносите единственную актуальную копию данных до обновления `CURRENT.md` и индексов.
- Не загружайте архивные файлы по умолчанию.
- При ссылке из актуального файла ясно помечайте материал как архивный.
- Git уже хранит историю версий; архив используйте для значимых объектов, которые всё ещё полезно находить по ссылкам.
